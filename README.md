# AI vs Cognitive Thinking Analysis

## Overview
This project was developed as part of my undergraduate research to analyze the relationship between Artificial Intelligence usage and cognitive thinking using statistical analysis.

## Objectives
- Collect survey data
- Clean and preprocess the dataset
- Perform ANOVA using Python
- Compare Python results with statistical analysis
- Interpret the findings

## Technologies Used
- Python
- Pandas
- NumPy
- SciPy
- Microsoft Excel

## Repository Contents
- ANOVA.py
- AI Cognitive Thinking Survey Data.csv (Anonymized)
- Output screenshots

## Note
The dataset has been anonymized to protect participant privacy.
